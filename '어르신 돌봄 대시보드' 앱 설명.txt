 '어르신 돌봄 대시보드' 앱 발표 자료

  1. 앱 소개


   * 앱 이름: 어르신 돌봄 대시보드 (Elder Care Dashboard)
   * 핵심 목표: 혼자 계신 어르신의 건강과 안전을 통합적으로 관리하고, 위험 상황을 감지하여 보호자에게 알리는
     것을 목표로 하는 웹 기반 모니터링 플랫폼입니다.

  2. 앱 실행 및 종료 방법


   * 실행: ElderCareApp.exe 파일을 더블클릭하여 실행합니다. 잠시 후 웹 브라우저에 대시보드가 자동으로
     나타납니다.
   * 종료: 앱을 완전히 종료하려면, 반드시 우측 상단의 빨간색 'Quit Application' 버튼을 클릭해야 합니다. 이
     버튼을 눌러야 백그라운드 서버까지 안전하게 종료되어 다음 실행에 문제가 없습니다.

  3. 핵심 기능 소개 및 사용법

  대시보드는 총 5개의 주요 기능(위젯)으로 구성되어 있습니다.


  ① 실시간 위험 감지 (Live Camera Feed)
   * 기능: 웹캠을 통해 어르신의 활동을 실시간으로 보여주고, AI 영상 분석 기술(OpenCV)을 활용하여 넘어짐과 같은
      갑작스러운 큰 움직임을 감지하여 경고합니다.
   * 사용법:
       1. 앱 실행 시 브라우저의 웹캠 사용 권한 요청에 '허용'을 클릭합니다.
       2. 실시간 영상이 화면에 나타납니다.
       3. 평소에는 상태가 초록색 'OK'로 표시됩니다.
       4. 넘어짐으로 의심되는 큰 움직임이 감지되면, 상태가 빨간색 'POTENTIAL FALL DETECTED'로 즉시 변경되어
          위험 상황을 알려줍니다.


  ② 어르신 프로필 (Senior's Profile)
   * 기능: 어르신의 이름, 나이, 주요 병력 등 핵심 정보를 한눈에 확인하고 관리합니다. 이 정보는 앱을 껐다 켜도
     유지됩니다.
   * 사용법:
       1. 'Edit Profile' 버튼을 클릭하여 수정 모드로 전환합니다.
       2. 이름, 나이, 병력 등을 수정한 후 'Save' 버튼을 눌러 정보를 저장합니다.


  ③ 복약 스케줄 (Medication Schedule)
   * 기능: 매일 복용해야 하는 약의 종류, 복용량, 시간을 목록으로 관리하여 잊지 않도록 돕습니다.
   * 사용법:
       1. 하단의 입력란에 약 이름, 복용량, 시간을 각각 입력합니다.
       2. 'Add Medication' 버튼을 누르면 목록에 추가됩니다.
       3. 삭제가 필요한 경우, 각 항목 옆의 'X' 버튼을 클릭합니다.


  ④ 긴급 연락처 (Emergency Contacts)
   * 기능: 가족, 주치의, 119 등 비상 상황에 필요한 연락처를 목록으로 관리하여 신속하게 대응할 수 있도록
     합니다.
   * 사용법:
       1. 하단의 입력란에 이름, 전화번호, 관계를 입력합니다.
       2. 'Add Contact' 버튼을 눌러 목록에 추가합니다.
       3. 'X' 버튼으로 삭제할 수 있습니다.


  ⑤ 일일 기록 (Daily Notes)
   * 기능: 그날의 어르신 건강 상태나 활동 중 특이사항을 간단히 메모하고 시간 순으로 확인할 수 있습니다.
   * 사용법:
       1. 텍스트 입력란에 내용을 작성합니다.
       2. 'Save Note' 버튼을 누르면, 현재 시간과 함께 기록이 목록 상단에 추가됩니다.

  1. 프론트엔드 (Frontend)


   * 구현 기술:
       * React: package.json 파일에 react, react-dom, react-scripts가 있는 것으로 보아, Facebook에서 만든
         사용자 인터페이스(UI) 라이브러리인 React를 기반으로 하고 있습니다. create-react-app을 통해 프로젝트가
          생성된 것으로 보입니다.
       * Bootstrap: package.json에 bootstrap이 포함되어 있어, 반응형 레이아웃과 UI 컴포넌트를 위해 Bootstrap
         프레임워크를 사용하고 있습니다.
       * JavaScript (JS): 핵심 로직은 JavaScript로 작성되었습니다.


   * 구조 및 기능:
       * src/App.js 파일이 애플리케이션의 메인 진입점 역할을 합니다.
       * UI는 여러 개의 작은 컴포넌트로 나뉘어 관리됩니다. src/components 폴더 안의 파일명을 통해 기능을
         유추할 수 있습니다.
           * WebcamFeed.js: 웹캠 영상을 화면에 보여주는 기능
           * Profile.js: 어르신의 프로필 정보 (이름, 나이 등) 관리
           * Medications.js: 복용 약물 스케줄 관리
           * Contacts.js: 비상 연락처 관리
           * Notes.js: 일일 특이사항 기록
       * App.js는 이 컴포넌트들을 조합하여 전체 대시보드 화면을 구성합니다.

  2. 백엔드 (Backend)


   * 구현 기술:
       * Python: 핵심 로_pre_dispatch
       * FastAPI: requirements.txt 파일에 fastapi가 명시되어 있습니다. 이는 현대적이고 빠른 고성능 웹
         프레임워크로, API 서버를 구축하는 데 사용됩니다.
       * Uvicorn: uvicorn은 FastAPI 애플리케이션을 실행하기 위한 ASGI(Asynchronous Server Gateway Interface)
         서버입니다.
       * SQLAlchemy: sqlalchemy 라이브러리를 사용하여 데이터베이스와 상호작용합니다. main.py에서 sqlite
         데이터베이스(elder_care_new.db)를 사용하는 것을 확인할 수 있습니다.
       * OpenCV: opencv-python 라이브러리를 통해 웹캠 영상 데이터를 처리합니다.
       * PyInstaller: build, dist, ElderCareApp.spec 파일이 있는 것으로 보아, Python 코드를 Windows용 단일
         실행 파일(.exe)로 패키징하기 위해 PyInstaller를 사용했습니다.


   * 구조 및 기능:
       * main.py 파일이 백엔드 서버의 모든 로직을 포함하고 있습니다.
       * API 제공: 프론트엔드에서 필요한 데이터(프로필, 약물 정보, 연락처 등)를 요청하면, 백엔드는
         데이터베이스에서 정보를 조회하여 JSON 형태로 응답합니다. (예: /api/profile, /api/medications)
       * 데이터베이스 관리: SQLAlchemy를 통해 프로필, 약물, 연락처, 메모 등의 정보를 SQLite 데이터베이스에
         저장, 수정, 삭제합니다.
       * 웹캠 영상 처리:
           * /ws/video 라는 WebSocket 엔드포인트를 제공합니다.
           * 프론트엔드(WebcamFeed.js)에서 전송된 웹캠 영상 프레임을 받습니다.
           * OpenCV를 사용하여 이전 프레임과 현재 프레임을 비교, 큰 움직임(motion)이 감지되면 "POTENTIAL FALL
             DETECTED" (낙상 가능성 감지)와 같은 상태 메시지를 프론트엔드로 다시 전송합니다.

  3. 종합적인 작동 원리


   1. 실행: 사용자가 PyInstaller로 빌드된 백엔드 실행 파일(ElderCareApp.exe)을 실행합니다.
   2. 서버 시작: 백엔드 프로그램은 내부적으로 Uvicorn 서버를 실행하여 localhost:8000에서 API 요청을 기다립니다.
       동시에 자동으로 웹 브라우저를 열어 프론트엔드 화면(http://127.0.0.1:8000)을 띄웁니다.
   3. 화면 표시: 브라우저에 React로 만들어진 '어르신 돌봄 대시보드' UI가 나타납니다.
   4. 데이터 연동: 프론트엔드 각 컴포넌트(프로필, 약물 등)는 페이지가 로드될 때 백엔드의 API(/api/...)를
      호출하여 데이터를 가져와 화면에 표시합니다.
   5. 영상 스트리밍 및 분석:
       * WebcamFeed 컴포넌트는 사용자의 웹캠에 접근하여 영상 데이터를 캡처합니다.
       * 캡처된 영상 프레임을 백엔드의 WebSocket(/ws/video)으로 실시간 전송합니다.
       * 백엔드는 OpenCV를 이용해 이 영상에서 움직임을 분석하고, 이상 상황(큰 움직임)이 감지되면 그 결과를 다시
         프론트엔드로 보내 화면에 경고를 표시합니다.
   6. 상호작용: 사용자가 프론트엔드에서 새로운 약물 정보를 입력하거나 메모를 작성하면, 해당 정보는 API를 통해
      백엔드로 전송되어 데이터베이스에 저장됩니다.
   7. 종료: 사용자가 대시보드의 'Quit Application' 버튼을 누르면, 프론트엔드는 백엔드에 /api/shutdown 요청을
      보내 서버 프로세스를 종료시키고 웹 페이지를 닫습니다.


  요약: 이 애플리케이션은 React 프론트엔드와 Python(FastAPI) 백엔드가 긴밀하게 연동되는 풀스택 구조입니다.
  백엔드는 데이터 관리와 영상 분석을, 프론트엔드는 사용자 인터페이스와 상호작용을 담당하며, 특히 웹캠을
  이용한 실시간 움직임 감지 기능이 핵심적인 역할을 합니다.

 1. 추가 가능한 기능 제안


  현재 앱은 훌륭한 기본 골격을 갖추고 있으며, 다음과 같은 기능들을 추가하여 더욱 완성도 높은 '어르신 돌봄
  솔루션'으로 발전시킬 수 있습니다.

  (1) 핵심 기능 고도화


   * 정교한 낙상 감지 (Advanced Fall Detection):
       * 현재: 프레임 간의 '큰 움직임'을 감지하는 방식은 오탐지(넘어진 게 아닌데 감지)나 미탐지(천천히
         쓰러지는 경우)의 가능성이 있습니다.
       * 개선: 자세 추정(Pose Estimation) AI 모델(예: MediaPipe, OpenPose)을 도입하여 사람의 관절과 신체
         부위를 인식하게 만듭니다. 이를 통해 '서 있는 자세'에서 '누워있는 자세'로 급격히 변하는 것과 같은 실제
          낙상 패턴을 훨씬 정확하게 감지할 수 있습니다.


   * 복약 관리 및 알림 (Medication Reminders & Logging):
       * 현재: 약물 목록을 보여주는 기능만 있습니다.
       * 개선: 지정된 복용 시간이 되면 화면에 알림(Notification)을 띄우거나 소리를 내어 어르신이 약 먹을
         시간을 잊지 않도록 돕습니다. 어르신이나 보호자가 '복용 완료' 버튼을 누르면, 복용 기록이
         데이터베이스에 저장되어 보호자가 원격으로 복약 이행 여부를 확인할 수 있습니다.

  (2) 새로운 기능 추가


   * 자동 긴급 연락 시스템 (Automated Emergency Alerts):
       * 개선: 낙상이 감지되었을 때 화면에 경고만 띄우는 것이 아니라, 등록된 비상 연락처로 자동으로 문자
         메시지(SMS)나 전화를 거는 기능을 추가합니다. 이를 위해서는 Twilio와 같은 외부 통신 API 서비스 연동이
         필요합니다. "낙상 의심 상황이 감지되었습니다." 와 같은 메시지를 자동으로 보낼 수 있습니다.


   * 원격 접속 및 다중 사용자 지원 (Remote Access & Multi-User):
       * 현재: localhost에서만 작동하므로, 보호자가 같은 컴퓨터에서만 대시보드를 볼 수 있습니다.
       * 개선: 백엔드 서버를 Heroku, AWS, Google Cloud와 같은 클라우드에 배포하여 인터넷이 되는 어디에서든
         접속할 수 있도록 만듭니다. 또한, 여러 보호자(자녀, 요양보호사 등)가 각자의 계정으로 로그인하여 정보를
          확인하고 기록을 남길 수 있는 다중 사용자 시스템을 도입합니다.


   * 양방향 소통 채널 (Two-way Communication):
       * 개선: 간단한 영상 통화 또는 음성 통화 기능을 추가합니다. 보호자가 원격에서 어르신의 상태를 직접 보고
         대화할 수 있어 정서적 안정감을 제공하고, 위급 상황 시 빠른 소통이 가능해집니다. WebRTC 기술을
         활용하여 구현할 수 있습니다.


   * 건강 데이터 시각화 (Health Data Visualization):
       * 개선: '일일 특이사항'에 기록된 내용이나 복약 기록 등을 바탕으로 어르신의 건강 상태 변화를 한눈에 볼
         수 있는 차트나 그래프를 제공합니다. 예를 들어, 특정 기간 동안의 활동량 변화, 복약 준수율 등을
         시각화하여 건강 이상 징후를 조기에 발견하는 데 도움을 줄 수 있습니다.

  2. 해결해야 할 보안점


  현재 앱은 로컬 환경에서 개인적인 사용을 가정하고 만들어져 있어 상용화 또는 원격 접속 기능을 추가하기 전에
  반드시 해결해야 할 보안 취약점들이 존재합니다.


   * 1. 인증 및 인가 부재 (Lack of Authentication and Authorization)
       * 문제점: 현재 앱은 로그인 기능이 없어 프로그램을 실행할 수 있는 사람이라면 누구나 모든 민감 정보(병력,
          연락처 등)에 접근하고 수정할 수 있습니다.
       * 위험성: 심각한 개인정보 및 의료 정보 유출로 이어질 수 있습니다.
       * 해결 방안:
           * 로그인 시스템 도입: 사용자 계정(ID/Password) 기반의 로그인 기능을 구현합니다.
           * API 엔드포인트 보호: 백엔드의 모든 API 요청에 대해 JWT(JSON Web Token)와 같은 인증 토큰을
             검증하는 절차를 추가하여, 로그인한 인가된 사용자만이 데이터에 접근할 수 있도록 제한해야 합니다.


   * 2. 안전하지 않은 서버 종료 기능 (Insecure Shutdown Endpoint)
       * 문제점: /api/shutdown 엔드포인트는 아무런 인증 없이 호출될 수 있습니다.
       * 위험성: 만약 서버가 외부에 노출되면, 악의적인 사용자가 이 API를 호출하여 원격으로 서버를 계속해서
         종료시키는 서비스 거부(DoS) 공격을 할 수 있습니다.
       * 해결 방안: 이 엔드포인트는 반드시 관리자 권한을 가진, 인증된 사용자만이 호출할 수 있도록 엄격한 인가
         절차를 추가해야 합니다.


   * 3. 암호화되지 않은 통신 (Unencrypted Communication)
       * 문제점: 현재는 http 및 ws (일반 WebSocket) 프로토콜로 통신합니다.
       * 위험성: 원격 접속 기능을 추가할 경우, 인터넷 망을 통해 전송되는 데이터(로그인 정보, 개인 정보, 영상
         데이터 등)를 중간에서 가로채는 '중간자 공격(Man-in-the-Middle Attack)'에 매우 취약합니다.
       * 해결 방안: 서버를 클라우드에 배포할 때, 반드시 SSL/TLS 인증서를 적용하여 모든 통신을 HTTPS 및
         WSS(Secure WebSocket)로 암호화해야 합니다.


   * 4. 입력값 검증 (Input Validation)
       * 문제점: FastAPI와 Pydantic을 사용하면 기본적인 타입 검증은 잘 이루어지지만, 모든 잠재적 위협을 막지는
          못할 수 있습니다.
       * 위험성: 악의적으로 조작된 입력값이 시스템 오류를 유발하거나, 드물지만 SQL 인젝션과 같은 공격의 빌미를
          제공할 수 있습니다.
       * 해결 방안: Pydantic 모델을 통해 데이터의 형식, 길이, 허용 가능한 값의 범위 등을 더욱 엄격하게
         정의하고, 모든 사용자 입력은 신뢰할 수 없다는 원칙하에 서버단에서 항상 검증하는 로직을 유지해야
         합니다.


  이러한 기능 개선과 보안 강화를 통해 elder-care-app은 단순한 프로토타입을 넘어, 실제 현장에서 유용하고
  안전하게 사용할 수 있는 완성도 높은 제품으로 거듭날 수 있을 것입니다.
